# Network

## 01 TCP 行エコーサーバー

C++のソケットAPIで、改行で区切ったメッセージを受信し、1行ずつそのまま返す。
Peterson と Davie の *Computer Networks: A Systems Approach*（v6.1）§1.4 と §5.2 を参照した実験。

TCPは順序付きのバイトストリームを提供する。送信側の書き込みと受信側の
`recv()` の境界は一致するとは限らない。そこで、改行までのバイト列を
バッファに残し、1回の受信に複数の改行があればそれぞれに応答する。
`send()` が一部だけ書き込んだ場合は、残りを送る。

Linux / WSLで実行できる。接続先は `127.0.0.1` で、クライアントを1接続ずつ
処理する。1行の上限は改行を除いて4096バイトで、超えると接続を閉じる。
切断時に残った改行のない行は破棄する。

### ビルドと検証

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic -O2 server.cpp -o tcp_echo
python3 test_echo.py -v
```

テストでは、受信バッファをまたぐ行、1回の送信に含めた複数行、
改行前の切断、行長の上限を検証する。

手動で試すには `./tcp_echo 9000` で起動し、別の端末から
`nc 127.0.0.1 9000` で接続して1行入力する。
